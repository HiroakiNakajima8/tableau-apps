# tableau-apps

Static web versions of Tableau Data Apps, hosted on GitHub Pages and embedded in Tableau Public via a Web Page object.

| App | URL |
| --- | --- |
| Typhoon Track Finder | https://hiroakinakajima8.github.io/tableau-apps/typhoon-track-finder/ |
| One Night on Dango-zaka (Chichibu Night Festival) | https://hiroakinakajima8.github.io/tableau-apps/one-night-on-dango-zaka/ |

Data: Typhoon Track Finder - IBTrACS (NOAA NCEI), coastline Natural Earth. One Night on Dango-zaka - festival timetable estimates from the Chichibu City timetable, Mapple, All About and Walkerplus; stars HYG v3.8.

Created by Manbow Nakajima.
